# 🎵 Music Player

A simple and responsive music player built using HTML, CSS, and JavaScript.

The music player allows users to play, pause, and switch between songs while displaying the song information and cover image.

# Features

- ▶️ Play music
- ⏸️ Pause music
- ⏮️ Previous song
- ⏭️ Next song
- 🔊 Volume control
- 📊 Music progress bar
- 🎵 Song title display
- 🖼️ Cover images
- 📱 Responsive design

# Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Audio API

# How to Run
Download or clone this repository.
Open the project folder.
Make sure the music files are inside the songs folder.
Make sure the cover images are inside the images folder.
Open index.html in your web browser.
Press the play button to start listening
