# Calculator

A simple and responsive calculator built using HTML, CSS, and JavaScript.

# Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear button
- ⌫ Delete button
- 📱 Responsive design
- ⌨️ Keyboard support

# Technologies Used

- HTML5
- CSS3
- JavaScript

# Project Structure

Calculator/
index.html
style.css
script.js

# How to Run
Download or clone this repository.
Open the project folder.
Open index.html in your web browser.
Start performing calculations
